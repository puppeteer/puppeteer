# Examples & Use cases

## Official examples

[The Puppeteer repository](https://github.com/puppeteer/puppeteer/tree/main/examples)
includes a small number of examples maintained by the Puppeteer team.

Follow the instructions in the README to run the examples. They cover use cases
such as generating PDFs from websites, taking screenshots, and intercepting
requests.

## Example suite

Find a collection of use-case-driven examples in Puppeteer's dedicated
[example repository](https://github.com/puppeteer/examples).

This suite is a growing collection of examples covering various use cases, such
as forwarding events from your Puppeteer process to the browser, interacting
with elements, and running CDP commands.

## Other projects, articles, and demos

See the following list for use cases and examples in areas such as rendering,
web scraping, and testing.

### Rendering and web scraping

- **[Puppetron](https://github.com/cheeaun/puppetron)**: A demo site that shows
  how to use Puppeteer and Headless Chrome to render pages. Inspired by
  [GoogleChrome/rendertron](https://github.com/GoogleChrome/rendertron), which
  is now archived.
- **[Thal](https://medium.com/@e_mad_ehsan/getting-started-with-puppeteer-and-chrome-headless-for-web-scrapping-6bf5979dee3e)**:
  A guide to getting started with Puppeteer and Chrome Headless for web scraping.
- **[pupperender](https://github.com/LasaleFamine/pupperender)**: Express
  middleware that checks the User-Agent header of incoming requests and, if it
  matches a configurable set of bots, renders the page using Puppeteer. Useful
  for progressive web app (PWA) rendering.
- **[headless-chrome-crawler](https://github.com/yujiosaka/headless-chrome-crawler)**:
  A crawler that provides APIs to control Headless Chrome and crawl dynamic
  websites.
- **[Puppeteer examples from Checkly](https://web.archive.org/web/20240811200732/https://www.checklyhq.com/learn/headless/basics-puppeteer-intro/)**:
  End-to-end Puppeteer examples for real-world use cases, such as extracting
  useful information from web pages and handling common login scenarios.
- **[browserless](https://github.com/browserless/browserless)**: A headless
  Chrome service that lets you execute Puppeteer scripts remotely.
- **[Puppeteer on AWS Lambda](https://github.com/jay-deshmukh/headless-chrome-with-puppeteer-on-AWS-lambda-with-serverless-framework)**:
  A guide to running Puppeteer on AWS Lambda with the Serverless Framework.
- **[Crawlee](https://github.com/apify/crawlee)**: A web scraping and browser
  automation library for Node.js and TypeScript. It supports Puppeteer,
  Playwright, Cheerio, JSDOM, and raw HTTP, with proxy rotation.

### Testing

- **[angular-puppeteer-demo](https://github.com/Quramy/angular-puppeteer-demo)**:
  A demo repository showing how to use Puppeteer with Karma.
- **[mocha-headless-chrome](https://github.com/direct-adv-interfaces/mocha-headless-chrome)**:
  A tool that runs client-side Mocha tests from the command line using Headless
  Chrome.
- **[puppeteer-to-istanbul-example](https://github.com/bcoe/puppeteer-to-istanbul-example)**:
  A demo repository showing how to export Puppeteer coverage data in Istanbul
  format.
- **[jest-puppeteer](https://github.com/argos-ci/jest-puppeteer)**: An almost
  zero-configuration tool for running Jest tests with Puppeteer. It also
  includes an assertion library for Puppeteer.
- **[puppeteer-har](https://github.com/Everettss/puppeteer-har)**: A tool for
  generating HAR files with Puppeteer.
- **[puppetry](https://puppetry.app/)**: A desktop app for building Puppeteer-
  and Jest-driven tests without writing code.
- **[puppeteer-loadtest](https://github.com/svenkatreddy/puppeteer-loadtest)**:
  A command-line tool for load-testing Puppeteer scripts.
- **[cucumber-puppeteer-example](https://github.com/mlampedx/cucumber-puppeteer-example)**:
  An example repository demonstrating how to use Puppeteer with Cucumber for
  integration testing.
